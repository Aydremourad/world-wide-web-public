WORLD WIDE WEB — PUBLIC VERSION

A lightweight web portal designed to work on early iPhone Safari and other old browsers.

Included:
- Google
- Wikipedia
- News
- Apple
- Old Museum
- Flight Track
- Old Search Engine

Flight Track includes quick airport links for Chicago O'Hare (ORD), New York JFK (JFK), and Los Angeles (LAX).

This public version is based on the original World Wide Web project and keeps the same 320px first-iPhone-era interface and old-browser compatibility.
